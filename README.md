# Psikotes Online - MindMetrix

Aplikasi web sederhana untuk Psikotes Online yang interaktif dan modern.

## Cara Menggunakan
1. Buka file `index.html` dengan browser Anda (Chrome/Firefox/Edge).
2. Anda akan masuk ke halaman beranda.
3. Klik "Mulai Tes" untuk mencoba fitur psikotes.
4. Klik "Admin" untuk masuk ke panel admin.
   - **Password Default Admin**: `admin123`

## Fitur
- **Tes Interaktif**: Soal pilihan ganda dengan timer.
- **Skoring Otomatis**: Hasil langsung keluar setelah tes selesai.
- **Analisis Kepribadian**: Penjelasan tipe kepribadian berdasarkan skor.
- **Admin Panel**: Tambah/Hapus soal dan melihat riwayat hasil peserta.
- **Penyimpanan**: Data tersimpan di browser (Local Storage) sehingga tidak hilang saat direfresh (untuk browser yang sama).

## Teknologi
- HTML5, CSS3 (Modern Variables & Glassmorphism), Vanilla JavaScript.
- Icons by Lucide (CDN).
- Font by Google Fonts (Outfit & Plus Jakarta Sans).
